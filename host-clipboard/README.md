# Sunshine 텍스트 클립보드 패치

Moonlight와 Sunshine 사이에서 새로 복사한 텍스트를 양방향으로 전달합니다. 한글·이모지를 지원하고 동일 내용의 반복 전송/덮어쓰기를 억제합니다. 이미지와 파일 전송은 포함하지 않습니다.

- 기반 Sunshine: `2026.914.233613`
- 기반 소스 커밋: `63d35f702ee9e362e43263742981836ec0710384`
- 패치: `sunshine.patch`
- 호스트 테스트: `tests/test_pen_clipboard.cpp`와 패치에 포함된 같은 테스트
- 설치기: `package/install.ps1`, 원본 검사: `package/validation.ps1`

Sunshine 소스의 해당 커밋에서 패치를 적용한 뒤 빌드합니다. 패치에는 `src/stream.cpp`, `src/pen_clipboard`와 테스트 변경이 들어 있습니다. 클라이언트의 `shared/clipboard`와 호스트 헤더는 같은 구현입니다.

설치기는 검증된 공식 MSI/lite ZIP 실행 파일 또는 이전 클립보드 패치만 허용합니다. 원본을 백업하고 서비스 중지·복사·재시작 실패 시 실행 파일을 되돌립니다. 다른 버전을 자동으로 덮어쓰거나 버전 문자열만으로 허용하지 않습니다. 직접 빌드했다면 새 실행 파일의 해시를 별도 패키지 매니페스트에 기록해야 합니다.

양쪽 프로그램이 패치를 지원해야 하며, 노트북의 호스트 타일 메뉴에서 **클립보드 텍스트 공유**를 켭니다. 공유는 호스트별로 저장합니다. 기존 GameStream 제어 연결의 암호화를 사용하며 별도 서버·포트를 추가하지 않습니다. 텍스트 최대 크기는 1MiB입니다.

테스트는 유니코드·양방향 전달·청크·확인 응답·재접속·경합·잘못된 프레임·동일 텍스트 반복 억제를 포함합니다. 실제 양방향 텍스트 전송은 사용자 확인을 받았습니다. r3의 Win+V 반복 갱신 방지는 격리된 네이티브 테스트를 통과했으며 두 PC 실제 화면 확인은 별도로 구분합니다.
