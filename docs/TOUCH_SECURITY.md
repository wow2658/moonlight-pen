# 손터치 다운로드 도구의 보안 검토

검토 대상은 `v2026.11.15-uninstall1`의 `03-Laptop-Finger-Touch.zip`입니다. 외부 보안 감사나 모든 취약점의 부재를 보증하는 문서는 아닙니다.

## 권한과 실행 경로

손터치 HID 장치 전환에는 관리자 권한이 필요합니다. 설치 시 프로그램을 `C:\Program Files\Laptop Finger Touch Toggle`에 두고 SYSTEM/Administrators 쓰기, Users 읽기·실행 권한을 설정합니다. 디렉터리와 실행 파일의 소유자·쓰기/삭제/권한 변경 허용 규칙을 확인하고, 재분석 지점(심볼릭 링크·정션 등)이 포함된 경로는 거부합니다.

로그인 예약 작업은 현재 계정의 대화형 세션에서 고정된 수신기와 `--listen`만 실행합니다. 비밀번호를 저장하지 않습니다. 수신기는 고정된 원본 파일의 SHA256을 매번 확인하고 허용한 `--status`, `--toggle`, `--on`, `--off`만 직접 실행합니다. 셸 명령, 파일 경로, 네트워크 요청을 외부 입력으로 받지 않습니다. 자식에 상속하는 핸들은 상태 파이프와 NUL 입력으로 제한합니다.

설치 PowerShell은 시스템 모듈 경로만 사용합니다. 실행 파일은 정적 CRT로 빌드하며 시작 시 DLL 해석과 이후 동적 로드 모두 System32로 제한합니다. ASLR·DEP·CFG·높은 주소 엔트로피 옵션을 사용합니다. 받은 ZIP 자체가 신뢰할 수 없는 출처에서 변조된 경우까지 내부 해시가 보호하는 것은 아닙니다.

## 장치 선택과 개인정보

개인의 장치 인스턴스 ID나 부모 인스턴스의 접미부를 실행 파일·설정 파일에 넣지 않습니다. 실행하는 PC의 현재 장치 목록에서 다음을 읽어 확인합니다.

- 모델이 **940X3M**인지 확인
- STMD1234 COL01의 손터치 HID 용도 `0D:04`와 STMD1234 ACPI 부모 확인
- 별도 WCOM0032 COL02의 펜 HID 용도 `0D:02`와 WCOM0032 ACPI 부모 확인
- 각각 하나의 후보인지, 서로 다른 장치와 부모인지 확인

지원하지 않는 모델·여러 후보·잘못된 용도/부모에서는 중단합니다. 일반적인 HID 전체, 터치패드, I2C 버스 전체를 비활성화하지 않습니다. 장치 식별 결과는 로컬 메모리에서만 사용하며 로그에 고유 ID를 남기지 않습니다.

네트워크·서버·텔레메트리·전체 키보드 후킹·키 입력 내용 기록·클립보드 접근 기능이 없습니다. `RegisterHotKey`로 Ctrl+Alt+F10만 받습니다. 방화벽·백신 예외나 보안 기능 비활성화를 추가하지 않습니다. 짧은 로컬 로그에는 시각·처리 시간·상태만 저장하며 64KiB를 넘으면 비웁니다.

## 동작과 실패 처리

정상 작동한 원본 백엔드의 장치 변경 절차와 최초 100ms 대기·S펜 확인을 유지했습니다. 수신기는 장치 변경 API를 직접 호출하지 않습니다. 전환 뒤 PnP 상태 외에 Windows 포인터·Raw HID·터치 등록과 별도 S펜 상태를 확인합니다. 상태가 맞지 않으면 추가 자동 전환을 중단하고 반복 복구를 시도하지 않습니다.

설치/확인 과정에서 자동 OFF/ON 시험을 하지 않습니다. 배포용 백엔드의 `--self-test`는 거부됩니다. 설치기는 기존 정상 원본/수신기가 실행 중이면 그대로 유지하고, 다른 기존 버전을 자동 교체하지 않습니다. 제거는 이 배포판 또는 확인된 초기 정상 설치의 해시와 현재 계정의 고정 예약 작업을 확인한 뒤 진행하며, 먼저 손터치 켜기를 요청합니다. 자기 상태 로그와 비어 있는 설치 폴더도 정리합니다. 재귀 삭제는 하지 않습니다.

## 수행한 검사와 한계

- `/W4 /WX` 빌드, 지원 모델·포맷 후 인스턴스 접미부 변경·중복·용도/부모/접두어 거부 단위 검사
- 현재 940X3M에서 배포 백엔드와 설치 `Check`의 실제 읽기 전용 확인
- 설치기 변조/누락 파일·소유자·일반 사용자 쓰기/삭제/권한 인수·리다이렉트 거부 검사와 SID/계정명 동일 사용자 확인 14개
- ZIP CRC·내부 매니페스트·SHA256·개인 비교값·비밀정보 검사
- 실행 파일의 DLL 의존성, 보안 빌드 플래그와 소스의 네트워크/임의 명령 입력 부재 확인

원래 구성의 실제 손터치 OFF/ON·S펜 유지·반응 개선은 사용자 확인을 받았습니다. 이번 다운로드용 구성으로 실제 장치를 다시 OFF/ON하거나 새 Windows에서 설치 전체를 시험하지는 않았습니다. 정상 표시만으로 실제 손가락 입력 복구를 보증하지 않으며, 실제 확인 절차를 안내에 포함했습니다.

실행 파일은 코드 서명되지 않았습니다. SmartScreen/백신 경고가 나올 수 있으며 경고를 없애려고 보안 기능을 끄거나 일괄 예외를 추가하지 않습니다. SHA256은 파일 동일성 확인 자료이며 디지털 서명을 대신하지 않습니다. 관리자 권한을 가진 악성코드나 관리자에 의한 프로그램/예약 작업 변경을 막는 보안 경계는 아닙니다.

삭제 경로 추가판에서는 01/02/03 모두 루트의 `삭제.cmd`를 제공합니다. 03은 확인된 초기 정상 설치도 같은 경로로 지우며, 손터치 켜기를 먼저 요청하고 새/구 예약 작업의 소유 관계를 확인합니다. 테스트에서는 실제 장치나 작업을 바꾸지 않고 모의 처리했습니다.
