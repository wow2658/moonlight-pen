# 전체 화면·HEVC 통합 실행판

버전: `v2026.11.17-fullscreen-hevc1` / Windows x64

기존 전체 화면 전환 수정 클라이언트와 HEVC 보안 수정 DLL을 함께 넣은 별도 포터블 패키지입니다. 이미 컴파일된 파일을 검증해 조합했으며, 이번 패키지 제작 중 소스를 새로 컴파일하지 않았습니다.

| avcodec-63.dll | `078b14fd1297e87a086ad7ed9abaa6f0af9a8bad945bbd240e6c8ec8742e8ab1` | [FFmpeg 패치 자료](../../ffmpeg/README.md) |

공개 ZIP의 SHA-256은 `2591eeb1471ab0f347bbd25a0d7dacec7f442ebda075523e129f08c9c193496c`입니다. 패키지의 `BUILD-INFO.json`에는 구성 파일과 소스 출처를 기록했습니다. FFmpeg 기준 소스 아카이브와 패치, 라이선스를 동봉했습니다.

## 이번 통합 패키지에서 확인한 것

- 내부 파일 1,671개의 ZIP CRC 및 매니페스트 대상 1,670개의 SHA-256 일치.
- 공개 ZIP의 개인 프로필 파일 0개.
- `--version`, `--help` 종료 코드 0, 표준 오류 출력 없음.
- 한국어 메인 화면 직접 관찰 및 전체 화면 수정 EXE·보안 수정 DLL의 실제 로드 경로와 해시 확인.
- 사용자가 창을 닫은 후 Moonlight 프로세스 0개 확인.
- 공개 폴더 Gitleaks 검사 탐지 0건. 바이너리를 포함한 패키지를 개인 프로필 기반 67개 비교값과 로컬 대조하여 검출 0건.
- 기존 정상판의 주요 실행 파일·설정·바로가기 보존 확인. 통합판의 별도 로컬 복사본에만 프로필을 복사함.
- 시작 확인 중 추가된 통합판 전용 방화벽 허용 규칙 두 개를 정리하고, 비교한 규칙 목록·주요 속성의 시작 전 일치 확인.

연결·재접속·H.264/HEVC D3D11VA 영상과 사용자 보고의 기본 펜 동작은 [앞선 노트북 시험 결과](security-trial01-20261117.md)에 구분해 기록했습니다. 새 통합 조합으로 스트리밍·전체 화면 전환·개별 필압 항목·외부망을 다시 시험한 결과로 확대하지 않습니다.

## 사용과 보존

기존 정상판과 다른 새 폴더에 압축을 풀고 `문라이트 실행.cmd`를 실행합니다. 실행기는 구성 해시를 확인하고 해당 `app`을 작업 디렉터리로 사용합니다. 다른 Moonlight가 실행 중이면 중단하며 강제 종료하지 않습니다.

기존 포터블 프로필이 필요하면 두 앱을 모두 닫고 새 앱의 첫 실행 전에 설정 복사 도구를 사용합니다. 원본은 읽기만 하며 이미 생성된 대상 프로필을 덮어쓰지 않습니다. 프로필이 복사된 개인 실행 폴더를 공개 ZIP으로 다시 포장하지 않습니다.

공개 다운로드의 02 호스트·03 손터치 파일은 r4 배포본과 바이트가 같습니다. 이번 01 업데이트를 위해 정상 동작 중인 r4 호스트를 재설치할 필요는 없습니다. 이전 릴리스와 다운로드 파일은 보존합니다.
