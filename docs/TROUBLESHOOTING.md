# 막혔을 때와 나중에 복구할 때

[처음 설치 순서로 돌아가기](../README.md)

## 문라이트 실행 창이 안 떠요

1. 다운로드한 것이 **01-Laptop-Moonlight-Pen.zip**인지 확인합니다. `Source code` ZIP은 실행 파일이 없습니다.
2. ZIP을 완전히 풀었는지 확인합니다. 폴더에 `문라이트 실행.cmd`와 `app`이 함께 있어야 합니다.
3. 이전 Moonlight를 종료하고 `문라이트 실행.cmd`를 실행합니다. 실제 프로그램은 `app/Moonlight.exe`입니다.
4. 실행기가 오류 메시지를 보여 주면 해당 메시지를 확인합니다. EXE나 DLL이 없다는 오류라면 파일 하나씩 보충하기보다 ZIP을 새 폴더에 다시 풉니다.
5. Windows 보안에서 차단했다면 표시된 파일명과 탐지명을 확인합니다. 보안 기능 끄기나 전체 폴더 예외 추가는 설치 절차에 포함하지 않습니다.

## 호스트 PC가 목록에 없어요 / 페어링이 안 돼요

1. 호스트에서 Sunshine이 실행 중인지 확인합니다.
2. 처음 연결할 때는 두 컴퓨터를 같은 공유기에 연결해 시도합니다.
3. 자동 검색이 안 되면 문라이트의 `+`에 호스트의 로컬 IP를 입력합니다. IP는 호스트의 Windows 네트워크 설정에서 확인합니다.
4. 문라이트에 나타난 PIN은 **호스트의 Sunshine 웹 화면 → PIN**에 입력합니다. GitHub 로그인 코드와는 별개입니다.
5. 새로 압축을 푼 실행 패키지는 기존의 페어링을 포함하지 않습니다. 다시 페어링하는 것이 정상입니다.

## 펜은 움직이는데 필압이 없어요

먼저 연결 중 `Ctrl+Alt+Shift+P`를 누르고 펜을 눌러 봅니다.

| 보이는 상태 | 확인할 곳 |
| --- | --- |
| IN / OUT 둘 다 움직이지 않음 | 노트북의 펜·드라이버·Windows Ink 입력부터 확인합니다. PTH-451은 **노트북에** 꽂습니다. |
| IN / OUT은 움직이지만 선 굵기가 같음 | 호스트 Sunshine의 펜 입력 수신, 그리기 앱의 Windows Ink 입력 설정, 브러시의 필압 크기/불투명도 설정을 확인합니다. |
| 표시된 기기 프로필이 다름 | 연결을 끊고 문라이트 설정 → 펜 필압 설정에서 **S펜 / PTH-451**을 직접 선택한 뒤 다시 연결합니다. |
| 너무 세게 눌러야 진해짐 | 설정에서 해당 기기의 **100%에 도달하는 입력 압력**을 낮춥니다. 중간 필압 감도를 왼쪽으로 옮기면 중간 선도 더 부드럽게 나옵니다. |

PTH-451: 노트북의 **와콤 타블렛 등록정보 → 펜 → 매핑 → Windows Ink 사용**을 켭니다. 앱별 설정이 있다면 Moonlight에 적용되는 항목도 확인하세요. 드라이버 설치 후 재부팅을 요구했다면 재부팅합니다. [공식 설명서](https://101.wacom.com/UserHelpPDF_Legacy/PTH-451_en.pdf)

Sunshine에는 `native_pen_touch` 설정이 있습니다. 호스트의 Sunshine 설정에서 네이티브 펜/터치 전달이 켜져 있는지 확인하고, 값을 바꾼 뒤 Sunshine의 적용·재시작 안내를 따릅니다. UI에 보이지 않으면 사용 중인 버전의 공식 설정 문서를 확인하세요. [Sunshine 공식 설정 문서](https://docs.lizardbyte.dev/projects/sunshine/latest/md_docs_2configuration.html)

## 복제 / 확장 / ? 버튼이 반응하지 않아요

이 기능은 **02 ZIP을 호스트 PC에 설치**해야 합니다. 노트북에 설치하는 것이 아닙니다.

1. 호스트에서 `호스트 설치.cmd`를 실행해 **PASS**를 확인합니다.
2. `설치된 바로가기 열기.cmd`를 실행합니다. 시작 메뉴에서 폴더를 찾지 않아도 됩니다.
3. 열린 폴더에서 **Check**를 직접 실행합니다. **호스트의 Windows 디스플레이 설정**이 열려야 합니다.
4. 호스트 키보드로 **Ctrl+Alt+Shift+H**를 누릅니다. 같은 설정 창이 열려야 합니다.
5. 노트북의 문라이트를 다시 연결하고 패널의 `?`를 누릅니다. 같은 설정 창이 열려야 합니다.
6. 마지막으로 **복제 / 확장**을 확인합니다. 모니터가 한 개뿐이거나 해당 배치가 지원되지 않으면 눈에 띄는 변화가 없을 수 있습니다.

| 어디까지 됐나요? | 다음 조치 |
| --- | --- |
| 설치가 실패함 | 오류 메시지를 확인합니다. Sunshine이 설치된 호스트에서 실행했는지 확인합니다. |
| Check 직접 실행만 됨 | Windows 바로가기 단축키가 아직 반영되지 않았을 수 있습니다. 호스트에서 작업을 저장하고 로그아웃 → 다시 로그인한 뒤 4번부터 확인합니다. |
| 호스트 키보드로는 되지만 ?가 안 됨 | 새 01 패키지로 실행 중인지 확인하고 스트리밍을 다시 연결합니다. |
| ?는 되지만 복제/확장이 안 됨 | 호스트에서 Clone / Extend를 직접 실행합니다. 직접 실행도 실패하면 호스트 Windows·디스플레이 구성 쪽을 확인합니다. |

화면 모드 전환 중 스트리밍이 끊기면 문라이트에서 다시 연결하세요.

**이 설치 방식은 추가 도우미 EXE를 사용하지 않습니다.** 예전에 받은 `Moonlight-Display-Helper.exe`나 `INSTALL-HOST.cmd`는 현재 권장 설치 파일이 아닙니다. 옛 EXE가 실행 중이면 트레이에서 종료하고 새 호스트 설치를 진행합니다.

## 다음 날 다시 쓰려면 뭘 켜야 하나요?

1. 호스트를 켜고 Sunshine이 실행 중인지 확인합니다.
2. 노트북에서 보관해 둔 폴더의 **문라이트 실행.cmd**를 실행합니다.
3. 호스트 → Desktop에 연결하고 그리기 앱을 엽니다.

호스트 설치 CMD는 매번 실행하지 않습니다. 호스트 화면 전환용으로 Tailscale이나 VirtualHere를 추가 실행할 필요도 없습니다. 인터넷을 통한 접속 경로를 따로 구성한 경우에는 그 접속 환경에 필요한 프로그램을 사용합니다.

## 새 PC로 옮기거나 재설치하려면?

- **노트북만 교체:** 새 노트북에 01 ZIP을 풀고 호스트와 다시 페어링합니다. PTH-451을 쓰면 드라이버와 Windows Ink도 설정합니다.
- **호스트만 교체:** 새 호스트에 Sunshine과 02 ZIP을 설치하고 노트북과 다시 페어링합니다.
- **둘 다 교체:** README의 1 → 2 → 3 순서대로 진행합니다.
- **실행 파일 업데이트:** 새 01 ZIP을 별도 폴더에 풉니다. 정상 연결과 필압을 확인한 다음 이전 폴더를 정리합니다.

## 내 설정은 어디에 저장돼요?

01 ZIP의 실행기는 `app`을 작업 폴더로 사용하며, 빈 `portable.dat` 표시 파일을 동봉합니다. 사용 후에는 다음과 같은 개인 파일이 생길 수 있습니다.

```text
01-Laptop-Moonlight-Pen/
  문라이트 실행.cmd
  app/
    Moonlight.exe
    portable.dat
    Moonlight Game Streaming Project/
      Moonlight.ini
```

`Moonlight.ini`에는 필압 설정과 페어링에 쓰이는 민감정보가 함께 들어갈 수 있습니다. 개인 백업으로 보관하고, GitHub 커밋이나 다른 사람에게 보낼 실행 ZIP에 넣지 마세요. 새 PC에서는 빈 패키지로 시작해 다시 페어링하는 방법을 권장합니다.

## 호스트 바로가기 삭제

02 패키지의 `호스트 바로가기 삭제.cmd`를 실행합니다. 이 작업은 설치한 Clone / Extend / Check 바로가기를 제거합니다. Sunshine 자체나 Windows 디스플레이 설정을 제거하는 작업은 아닙니다.
