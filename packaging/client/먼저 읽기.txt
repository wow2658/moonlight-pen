노트북용 Moonlight Pen — 처음 실행

1. 이 ZIP을 노트북에서 '모두 압축 풀기'로 풉니다.
2. '문라이트 실행.cmd'를 더블클릭합니다.
3. 호스트 PC를 선택하고, 처음이면 화면에 나온 PIN을
   호스트 PC의 Sunshine 웹 화면 > PIN에 입력합니다.
4. Desktop을 실행하면 호스트 화면에 연결됩니다.

PTH-451은 노트북에 꽂습니다.
노트북에 Wacom 드라이버 설치 후 와콤 타블렛 등록정보 > 펜 > 매핑 >
'Windows Ink 사용'을 켜세요. 호스트 그리기 앱도 Windows Ink 입력을 사용합니다.

연결 중 단축키
Ctrl+Alt+Shift+B : 화면 제어 패널
Ctrl+Alt+Shift+P : 필압 IN / OUT 표시 (기본 꺼짐)
Ctrl+Alt+Shift+O : 성능 통계 표시

S펜은 기본으로 입력 70% -> 전송 100%입니다.
연결을 끊고 설정 > 펜 필압 설정에서 조절한 뒤 다시 연결합니다.

복제/확장/?는 '02-Host-Display-Shortcuts.zip'을 호스트 PC에 설치해야 합니다.
노트북의 화면 구성을 바꾸는 기능이 아닙니다.

문라이트 실행.cmd와 app 폴더는 같이 보관하세요.
실행 파일만 꺼내거나 DLL을 삭제하면 실행되지 않습니다.
개인 설정과 페어링 정보는 포함하지 않았으므로 처음에는 다시 연결해야 합니다.
