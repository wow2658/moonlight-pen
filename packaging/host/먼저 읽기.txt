호스트 PC용 화면 전환 바로가기 — 처음 한 번만 설치

이 ZIP은 그리기 앱과 Sunshine이 설치된 데스크톱 PC용입니다.
펜을 꽂는 노트북에 설치하는 것이 아닙니다.

1. 호스트 PC에 Sunshine이 설치되어 있고 실행 중인지 확인합니다.
2. 이 ZIP을 '모두 압축 풀기'로 풉니다.
3. '호스트 설치.cmd'를 더블클릭합니다.
4. 검은 창에 PASS가 나오고 Clone / Extend / Check 폴더가 열리면 등록 완료입니다.
5. 노트북에서 새 문라이트로 다시 연결합니다.
6. Ctrl+Alt+Shift+B로 패널을 열고 ?를 누릅니다.
   호스트의 Windows 디스플레이 설정이 열리면 연결이 됩니다.
7. 복제 / 확장 버튼으로 호스트의 화면 모드가 바뀌는지 확인합니다.

시작 메뉴에서 설치된 폴더를 못 찾겠다면
  '설치된 바로가기 열기.cmd'를 실행하세요.

?가 반응하지 않으면
  설치된 폴더의 Check 직접 실행
  -> 호스트 키보드 Ctrl+Alt+Shift+H
  -> 노트북 문라이트의 ?
순서대로 확인하세요.
직접 실행만 되면 호스트에서 작업 저장 후 로그아웃/로그인을 한 번 해보세요.

매번 설치할 필요는 없습니다.
복제/확장 기능 없이 필압만 쓰면 이 ZIP은 생략할 수 있습니다.
이 패키지는 Windows 기본 프로그램에 단축키를 등록합니다.
Sunshine 패치나 별도 도우미 EXE는 필요하지 않습니다.
추가 EXE / DLL / 개인 설정 / 인증정보를 포함하지 않습니다.

삭제할 때: '호스트 바로가기 삭제.cmd'
