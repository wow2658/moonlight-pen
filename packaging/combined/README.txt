Moonlight Pen — 전체 화면 전환·HEVC 보안 보완 통합판

이 패키지는 전체 화면 전환 수정이 적용된 클라이언트와 HEVC 보안 수정 DLL을 함께 넣은 별도 포터블 실행판입니다.
기존 정상판을 보존하려면 새 폴더에 압축을 풀고 '문라이트 실행.cmd'를 실행하세요.
기존 정상판과 동시에 실행하지 않습니다. 설치나 관리자 권한은 필요하지 않습니다.

기존 설정을 복사할 때
- 정상판과 통합판을 모두 정상 종료합니다.
- 통합판을 처음 실행하기 전에 support/copy-portable-settings.ps1을 사용합니다.
- -NormalAppDirectory에는 기존 포터블 정상판의 app 폴더를 지정합니다.
- 원본은 읽기만 하며, 이미 통합판 프로필이 있으면 덮어쓰지 않습니다.
- 프로필 복사 후 이 로컬 폴더에는 개인 페어링 정보가 들어갈 수 있으므로 다른 사람에게 공유하지 마세요.
- 공개 다운로드 ZIP은 개인 프로필이 없는 상태입니다.

지금 잘 작동하는 Sunshine 호스트·페어링·공유기 설정을 바꿀 필요는 없습니다.
이 통합판은 클라이언트 업데이트이며, 기존 r4 호스트 도구와 함께 사용합니다.
앱 안의 기본 버전 표시는 같을 수 있습니다. BUILD-INFO.json의 구성과 SHA256으로 구분합니다.

소스·구성: SOURCE.txt와 BUILD-INFO.json
파일 무결성: FILES-SHA256.txt
FFmpeg 기준 소스와 패치: support/ffmpeg/

'삭제.cmd'는 이 새 폴더의 통합판·설정·정확히 해당 경로의 방화벽 규칙과 바로가기를 대상으로 합니다.
기존 정상판을 지우는 작업에는 사용하지 마세요.
