Moonlight + Sunshine 통합 복원 / 개인 보관용 / 2026-11-15

기존 테스트 폴더와 현재 설치는 바꾸지 않았습니다. Git 커밋/푸시는 하지 않았습니다.
이 묶음에는 문라이트 필압·화면 제어·텍스트 클립보드 r3, Sunshine 설치/패치,
호스트 복제·확장 단축키, 노트북 손터치 단축키 복원 자료가 들어 있습니다.
노트북과 호스트는 서로 다른 PC이므로 각 PC에서 해당 복원 파일을 한 번씩 실행합니다.

지금, 포맷 전에
1. 이 폴더 전체를 외장 드라이브 또는 업로드가 확인된 클라우드에 보관하세요.
2. 현재 Sunshine이 설치된 호스트 PC로 이 폴더 전체를 옮긴 뒤,
   02-Host\BACKUP-HOST.cmd를 실행하세요.
3. 생성된 02-Host\settings-backup.json을 이 복원 폴더에 함께 보관하세요.
   원래 호스트 설정을 가져오려면 이 파일이 필요합니다.
   현재 노트북에서는 호스트 설정 파일을 읽을 수 없어 아직 저장하지 못했습니다.
   이 파일은 앱 실행 경로 등 개인 정보를 담을 수 있으므로 공개하지 마세요.
4. 노트북 설정은 현재 확인한 값과 확정한 필압/UI 설정을 이미 넣었습니다.
   이후 복원판을 쓰면서 바꾼 값을 갱신하려면 01-Laptop\BACKUP-LAPTOP.cmd를 실행하세요.

포맷 후 — 호스트 PC
1. Windows/GPU/오디오 드라이버를 설치합니다.
2. 연결된 스트리밍을 종료하고 02-Host\RESTORE-HOST.cmd를 실행합니다.
   관리자 승인 한 번으로 공식 Sunshine 2026.914.233613 설치(없을 때),
   텍스트 클립보드 r3 패치, 백업한 영상·입력 설정, 화면 전환 단축키를 처리합니다.
   공식 MSI는 묶음에 포함돼 있어 별도로 버전을 찾을 필요가 없습니다.
   재부팅 요청이 나오면 재부팅하고 같은 파일을 다시 실행합니다.
   이미 다른 Sunshine 버전이 있으면 자동으로 다운그레이드하지 않고 멈춥니다.
3. Sunshine 웹 설정 https://localhost:47990 에서 웹 로그인 계정을 만듭니다.
   백업에서 제외한 계정 비밀번호·인증서·페어링은 새로 만듭니다.
4. Windows가 디스플레이/오디오 장치 ID를 바꿨으면 Sunshine에서 해당 장치를 다시 선택합니다.
   그림 앱은 Windows Ink/태블릿 PC 입력을 사용하도록 설정합니다.

포맷 후 — 펜을 연결하는 노트북
1. 노트북 드라이버를 설치하고 손터치/S펜이 먼저 정상 작동하는지 확인합니다.
   PTH-451도 쓰면 지원되는 Wacom 드라이버를 설치하고 Windows Ink 사용을 켭니다.
   Wacom 드라이버 자체와 그 앱의 설정은 이 복원 묶음에 포함하지 않았습니다.
2. 평소 사용할 Windows 관리자 계정으로 로그인하고
   01-Laptop\RESTORE-LAPTOP.cmd를 실행합니다.
   문라이트/필압·화면 설정, 바탕화면 바로가기, 손터치 단축키와
   해당 문라이트 실행 파일에만 적용되는 TCP/UDP 방화벽 허용 규칙을 만듭니다.
   방화벽 전체나 백신을 끄는 작업은 없습니다.
3. 바탕화면 '문라이트 복원판'을 실행하고 호스트를 추가해 PIN으로 다시 페어링합니다.
4. 호스트 타일의 메뉴에서 '클립보드 텍스트 공유'를 켭니다.
   또는 페어링을 마친 뒤 문라이트를 완전히 종료하고 같은 바로가기로 다시 켭니다.
   이 복원판의 실행기는 저장된 호스트들에 텍스트 공유를 켜도록 설정합니다.
   공유하면 양쪽에서 새로 복사한 텍스트가 상대방 클립보드에 전달됩니다.
   이미지/파일/클립보드 기록 전체의 동기화는 아직 지원하지 않습니다.
5. 호스트의 Desktop에 연결한 뒤 짧은 한글/이모지를 양방향으로 복사·붙여넣기합니다.
   Win+V를 열어 반복 갱신이 없는지도 확인합니다.

이번에 복원하는 기본 필압/UI
- 기기 선택: 자동. 내장 S펜 / 외장 PTH-451별 프로필.
- S펜: 원시 입력 70%에서 전송 100%, 감도 0.50.
- PTH-451: 원시 입력 100%에서 전송 100%, 감도 1.00.
- 필압 IN/OUT 표시: 기본 꺼짐. 끈 상태에서도 필압 보정은 적용됨.
- 오른쪽 아래 '화면' 상시 버튼: 숨김. 단축키 B로 패널을 열 수 있음.
- 해상도·FPS·비트레이트 등은 현재 확인한 일반 설정을 포함함.
- 이후 백업한 settings-backup.json이 있으면 그 파일의 값을 우선 사용함.

손터치 단축키 주의
Ctrl+Alt+F10은 이 Samsung 940X3M에서 사용자 확인을 마친 방식입니다.
손터치 끄기, S펜 유지, 다시 켜기, 반응 개선까지 확인했습니다.
포맷/드라이버 변경 후 장치 ID가 달라지면 설치기는 다른 장치를 임의로 끄지 않고 중단합니다.
그 경우 현재 HID 장치를 다시 확인해 이 노트북용으로 맞춰야 합니다.
자동으로 손터치를 껐다 켜는 테스트는 설치 중 하지 않습니다.
손터치가 안 돌아오면 반복 전환을 멈추고 Windows를 다시 시작하세요.

확인/복구
- 각 폴더의 CHECK.cmd: 패키지 파일과 설정 형식 검사. 설치/서비스 중지/터치 전환 없음.
- 02-Host\RESTORE-OFFICIAL.cmd: 클립보드 패치 전의 검증된 Sunshine 실행 파일로 복구.
  백업한 사용자 설정까지 과거로 되돌리는 명령은 아닙니다.
- 설치 결과: 01-Laptop\laptop-admin-result.txt, 02-Host\host-install-result.txt.
- 설치가 만든 Sunshine 설정 백업은 호스트 설치 폴더 config의 before-format-restore 파일.
- 보안 프로그램이 차단하면 탐지 내용을 확인하세요. 이 묶음은 보안 기능을 끄지 않습니다.

검증 범위
현재 노트북에서 실행 파일·설정·스크립트·ZIP 무결성과 모의 복원 검사를 합니다.
포맷한 Windows에서 MSI 설치부터 두 PC 연결까지 수행한 실제 시험은 아직 하지 않았습니다.
텍스트 공유는 양방향 작동 사용자 확인을 받았고, r3는 동일 텍스트 반복 쓰기 방지 수정판입니다.
r3의 두 PC Win+V 실제 화면 검증은 별도로 확인해야 합니다.
단축키 전체는 함께 들어 있는 '단축키 모음.md'를 참고하세요.
