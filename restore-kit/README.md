# 포맷 후 통합 복원 도구

이 디렉터리는 **복원 도구의 소스 템플릿**입니다. 실행 파일·공식 MSI·개인 장치 ID·설정 백업은 Git에 넣지 않습니다. 현재 개인용 완성 ZIP과 Git 소스 템플릿을 구분하세요.

완성 묶음은 각 PC에서 한 번씩 실행합니다.

| PC | 시작 파일 | 복원 내용 |
| --- | --- | --- |
| 펜을 연결하는 노트북 | `01-Laptop/RESTORE-LAPTOP.cmd` | 문라이트·필압/UI 설정·손터치 단축키·프로그램별 방화벽 규칙 |
| Sunshine 호스트 | `02-Host/RESTORE-HOST.cmd` | 맞는 Sunshine 버전·텍스트 클립보드 패치·호스트 설정·화면 단축키 |

## 개인용 완성 묶음 만들기

저장소 밖의 새 폴더를 출력 위치로 사용합니다. `assemble.py --help`에 입력 목록이 있습니다. 검사한 클라이언트/호스트 ZIP, 공식 Sunshine MSI, 정상 작동하는 손터치 실행 파일 두 개, 직접 확인한 개인 장치 프로필이 필요합니다. 개인 프로필 JSON은 `03-Touch/device-profile.local.json.example` 형식이며 실제 값은 Git 밖에 보관합니다.

이 도구는 파일을 조립하고 해시를 기록합니다. 프로그램 실행·서비스 중지·장치 전환·방화벽 변경은 하지 않습니다. 개인 설정 INI/키/인증서가 들어 있는 사용 중인 앱 폴더를 원본으로 삼지 않습니다.

조립 후에는 완성 폴더의 `00-먼저 읽기.txt` 순서를 따릅니다. 포맷 전 현재 호스트에서 `BACKUP-HOST.cmd`를 실행해 만든 `settings-backup.json`까지 완성 폴더와 함께 보관합니다. Git에는 올리지 마세요. 노트북 일반 설정은 허용 목록으로 추출하고, 호스트 백업에서도 인증서·비밀번호·페어링·환경변수 등을 제외합니다. 앱 경로 등 개인 정보는 남을 수 있습니다.

Sunshine 로그인과 PIN 페어링, 노트북/Wacom 드라이버 및 Windows Ink 설정은 새 설치에서 다시 확인합니다. 장치 ID가 달라졌으면 손터치 프로필을 다시 맞춥니다. 포맷한 Windows에서 설치부터 두 PC 연결까지의 실제 시험은 아직 수행하지 않았습니다.

단축키는 [단축키 모음](단축키%20모음.md)에 적용 PC·충돌·유지 여부를 정리했습니다. 노트북에서는 `Ctrl+Alt+Shift+B` 패널의 복제/확장 버튼을 사용합니다. 호스트용 D/E/H를 노트북에서 직접 누르면 Moonlight 단축키와 충돌할 수 있습니다.
