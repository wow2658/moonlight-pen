# 단축키와 적용 범위

`Ctrl+Alt+Shift` 세 키를 함께 누르는 문라이트 단축키와, `Ctrl+Alt+F10` 손터치 단축키를 구분하세요.

| 단축키 | 어디에서 누르나요? | 동작 / 알아둘 점 |
| --- | --- | --- |
| **Ctrl+Alt+F10** | 노트북 어디서나. Moonlight 연결 불필요 | **손가락 터치스크린만 끄기/켜기. S펜 유지.** 터치패드 전환 키가 아닙니다. 로그인 시 별도 수신기가 실행됩니다. |
| **Ctrl+Alt+Shift+K** | 노트북의 Moonlight 스트리밍 창 | **Windows 키 등 시스템 키를 호스트로 보낼지 전환.** 호스트로 잡으면 Win+V 등도 호스트에 전달됩니다. 다시 누르면 로컬 우선으로 돌아옵니다. 연결 중 전환이며 영구 설정은 문라이트 설정의 시스템 키 캡처 항목에서 지정합니다. |
| **Ctrl+Alt+Shift+B** | Moonlight 스트리밍 중 | 화면 제어 패널 열기 / 버튼·필압 막대까지 완전히 숨기기. 다시 누르면 패널이 열립니다. |
| **Ctrl+Alt+Shift+1** | Moonlight 스트리밍 중 | 호스트 모니터 1로 전환 요청. Sunshine의 나열 순서라 Windows 화면 번호와 다를 수 있습니다. |
| **Ctrl+Alt+Shift+2** | Moonlight 스트리밍 중 | 호스트 모니터 2로 전환 요청. 모니터가 존재해야 합니다. |
| **Ctrl+Alt+Shift+P** | Moonlight 스트리밍 중 | 필압 IN(입력) / OUT(보정 후 전송) 표시 켜기/끄기. 표시를 꺼도 보정은 적용됩니다. |
| **Ctrl+Alt+Shift+O** | Moonlight 스트리밍 중 | 성능 통계 켜기/끄기. 이 수정판에서는 원래 S였던 것을 O로 변경했습니다. |
| **Ctrl+Alt+Shift+X** | Moonlight 스트리밍 중 | 전체 화면 / 창 모드 전환. |
| **Ctrl+Alt+Shift+Z** | Moonlight 스트리밍 중 | 마우스/키보드 입력 잡기 전환. 창 밖으로 마우스를 꺼낼 때 사용합니다. |
| **Ctrl+Alt+Shift+Q** | Moonlight 스트리밍 중 | 스트리밍 종료 요청. |

## 복제·확장·호스트 설정

화면 제어 패널을 `Ctrl+Alt+Shift+B`로 열면 **복제 / 확장 / ?** 버튼을 사용할 수 있습니다.
버튼은 아래 호스트 바로가기에 해당하는 키를 보내고, 호스트 Windows가 실행합니다.

| 호스트에 등록되는 키 | 동작 | 직접 확인하는 방법 |
| --- | --- | --- |
| Ctrl+Alt+Shift+D | 호스트 디스플레이 복제 | 호스트 시작 메뉴 → Moonlight Display Shortcuts → Clone |
| Ctrl+Alt+Shift+E | 호스트 디스플레이 확장 | 같은 폴더의 Extend |
| Ctrl+Alt+Shift+H | 호스트 Windows 디스플레이 설정 열기 | 같은 폴더의 Check |

**D/E/H는 호스트 측 등록 키입니다.** 노트북의 Moonlight에서 같은 키를 직접 누르면 문라이트 자체 단축키(D는 최소화, E는 종료)와 충돌할 수 있으므로, **노트북에서는 B 패널의 버튼을 사용하세요.** 호스트 키보드에서 직접 시험하거나 시작 메뉴의 바로가기를 실행할 수 있습니다.

설치 후 단축키가 아직 반응하지 않으면, 호스트에서 작업을 저장한 뒤 로그아웃/로그인해 Windows가 바로가기를 다시 읽게 합니다. 먼저 Check를 직접 실행해 설정 화면이 열리는지 확인하세요.

## 자주 헷갈렸던 점

- Win+V가 어느 PC에서 열리는지는 **K의 시스템 키 캡처 상태**와 관련 있습니다. 텍스트 공유 기능의 켜짐/꺼짐과 별개입니다.
- 손터치 단축키는 **F10**입니다. Ctrl+Alt+F11은 다른 프로그램이 등록한 것으로 확인됐지만, 그 프로그램의 정체와 기능은 확인하지 않았습니다.
- S펜을 화면에 가까이 댄 상태에서는 기기의 손바닥 방지가 손가락을 막을 수 있습니다. 손터치 켜짐을 시험할 때는 S펜을 화면에서 떨어뜨리세요.
- 화면 복제/확장은 **호스트 PC**에 적용합니다. 노트북 화면 복제/확장 버튼이 아닙니다.
- 펜 프로필 수정은 연결을 끊고 문라이트 설정에서 합니다. 바꾼 값은 다음 연결부터 적용합니다.
