손터치 전환 — Samsung 940X3M 전용 / Ctrl+Alt+F10

이 ZIP은 손가락 터치스크린만 켜고 끄는 별도 도구입니다. S펜은 유지합니다.
Moonlight를 켜거나 스트리밍할 필요가 없습니다. 호스트에는 설치하지 않습니다.
다른 모델과 터치패드는 지원하지 않습니다.

설치
1. ZIP 전체를 '모두 압축 풀기'로 풉니다.
2. 펜을 쓰는 노트북에서 CHECK.cmd를 실행합니다. 관리자 권한 승인이 나올 수 있습니다.
   이 검사는 파일 해시·모델·손터치와 별도 S펜만 확인하며 장치를 끄지 않습니다.
3. PASS가 나오면 INSTALL.cmd를 실행합니다.
   프로그램을 보호된 Program Files에 복사하고 현재 계정의 로그인 시 자동 실행을 등록합니다.
   기존 정상 설치가 이미 있으면 유지하고 덮어쓰지 않습니다.
4. Ctrl+Alt+F10을 한 번 눌러 손터치가 꺼지고 S펜은 되는지 확인합니다.
5. 다시 한 번 눌러 켠 뒤 S펜을 화면에서 떨어뜨리고 손가락 터치가 실제로 되는지 확인합니다.

바탕화면에 '손터치 전환'과 '손터치 켜기' 바로가기가 만들어집니다.
이미 이 도구를 잘 쓰고 있다면 재설치할 필요가 없습니다.
새 배포판의 모델/장치 자동 식별과 설치기는 읽기 전용·모의 검사로 확인했습니다.
원래 프로그램의 실제 OFF/ON + S펜 유지·속도 개선은 이 모델에서 사용자 확인을 받았습니다.
새 배포판으로 실제 장치를 다시 OFF/ON하는 시험이나 새 Windows 설치 전체 시험은 하지 않았습니다.

개인정보와 권한
- 장치 인스턴스 ID·계정 SID·사용자명·인증서·개인키·Moonlight 페어링 정보가 ZIP에 들어 있지 않습니다.
- 실행하는 PC에서 장치를 읽어 확인합니다. 식별 결과를 외부로 보내거나 파일로 저장하지 않습니다.
- 네트워크 연결·서버·방화벽 예외·백신 예외·키 입력 내용 수집·클립보드 접근 기능이 없습니다.
- 관리자 권한은 손터치 장치 전환과 설치에 사용합니다. 일반 사용자가 수정할 수 없는 폴더에 설치합니다.
- 고정된 원본 실행 파일과 정해진 명령만 실행하고, 수신기가 원본 SHA256을 매번 확인합니다.
- 로그에는 시간·처리 시간·정상/이상 상태만 남습니다. 장치 고유 ID나 입력한 글자는 기록하지 않습니다.
- 모델/장치가 다르거나 후보가 여러 개이면 중단합니다. 임의로 비슷한 장치를 고르지 않습니다.
- 자동으로 손터치를 끄고 켜는 설치 시험은 없습니다.

보안 경고가 나올 때
이 배포판은 유료 코드 서명이 없는 자체 빌드입니다. Windows SmartScreen/백신의 경고가 나올 수 있습니다.
경고를 없애려고 스마트 앱 컨트롤·백신·방화벽을 끄거나 폴더 전체를 예외 등록하지 마세요.
공식 저장소의 Release에서 받았는지, SHA256SUMS.txt와 파일이 일치하는지 확인하고 탐지 내용을 검토하세요.
해시는 받은 파일의 동일성을 확인하는 자료이며 작성자 신원을 보증하는 디지털 서명은 아닙니다.
검사 통과가 모든 보안 문제의 부재를 보증하지는 않습니다.

문제가 생기면
- 다른 프로그램에서 Ctrl+Alt+F10을 쓰고 있으면 설치/자동 실행이 중단될 수 있습니다.
- 켜짐 표시인데 손터치가 안 돌아오면 반복 전환을 멈추고 Windows를 다시 시작하세요.
- 포맷 후에도 같은 모델·같은 종류의 손터치/펜이면 개인 ID를 복사하지 않고 다시 식별합니다.
  드라이버가 달라졌으면 먼저 노트북 드라이버를 설치하고 CHECK.cmd로 확인하세요.
- UNINSTALL.cmd는 이 배포판과 일치하는 설치만 제거합니다. 먼저 손터치 켜기를 요청한 뒤 자신의 작업/파일만 지웁니다.
  과거 다른 버전은 자동 제거하지 않습니다. 실행 기록은 남깁니다.

배포 파일
app\TouchToggle.exe: 처음 정상 작동한 장치 전환 절차 + 지원 모델/장치 확인.
app\TouchDispatcher.exe: Ctrl+Alt+F10 수신 + 고정된 원본 호출 + Windows 입력 등록 확인.
setup.ps1: 설치/확인/제거. 프로그램 실행·설정 파일의 해시를 패키지에서 확인.
