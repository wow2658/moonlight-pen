# 노트북 손터치 단축키

`Ctrl+Alt+F10`으로 노트북 전체의 손가락 터치스크린만 끄고 켭니다. S펜은 유지합니다. Samsung 940X3M에서 실제 끄기·다시 켜기·S펜 유지·반응 속도 개선을 확인했습니다.

`TouchToggle.cpp`는 정상 작동했던 원본의 한 번 실행하는 장치 제어 절차입니다. 전환 뒤 최초 100ms 대기를 포함합니다. `TouchDispatcher.cpp`는 단축키만 상주해서 받고 원본 프로그램을 직접 실행합니다. 수신기는 장치 변경 API를 직접 호출하지 않으며, 백엔드 해시와 Windows 터치 등록·S펜 상태를 따로 확인합니다. 상태가 맞지 않으면 추가 자동 전환을 멈춥니다.

## 개인 장치 프로필

이 저장소에는 실제 PC의 장치 인스턴스 ID를 넣지 않습니다. `device-profile.local.h.example`을 저장소 밖으로 복사하고, 확인한 손터치와 별도 S펜의 정확한 인스턴스 ID·부모 장치를 입력합니다. 다른 노트북의 값을 추측해 사용하지 마세요. I2C 버스 전체나 공통 부모를 끄는 방식이 아닙니다.

x64 MSVC 개발자 명령 프롬프트에서 다음 형식으로 빌드합니다. 두 경로는 저장소 밖의 로컬 경로를 사용합니다.

```bat
scripts\build-touch-tools.cmd PRIVATE_PROFILE_DIRECTORY OUTPUT_DIRECTORY
```

빌드는 백엔드의 SHA256을 계산해 개인 프로필에 고정한 뒤 수신기를 빌드합니다. 빌드 자체는 프로그램 설치·단축키 등록·장치 전환을 하지 않습니다. 기존에 정상 작동하는 프로그램을 자동 교체하지 않습니다.

현재 수신기는 보호된 `C:\Program Files\Laptop Finger Touch Toggle`에 설치한 원본을 실행합니다. 설치 스크립트와 자동 실행 등록은 `restore-kit/03-Touch`에 있습니다. 설치 때 현재 계정으로 새 예약 작업을 등록하므로 과거 SID나 작업 XML을 복사할 필요가 없습니다.

## 검증

`--status`와 수신기의 `--inspect`는 읽기 전용입니다. 설치 중 자동으로 끄기/켜기 왕복 시험은 수행하지 않습니다. 실제 확인은 한 번 눌러 손터치 차단·S펜 작동을 확인한 뒤, 다시 한 번 눌러 손터치가 돌아오는지 확인합니다. 켜짐 표시만으로 성공이라고 판단하지 않습니다.

포맷/드라이버 변경 후 장치 ID가 달라졌으면 프로필부터 다시 확인해야 합니다. 손터치가 돌아오지 않으면 반복 전환을 멈추고 Windows를 다시 시작하세요. 프로필·실행 파일·실행 기록은 개인 복원 묶음으로 보관합니다.
