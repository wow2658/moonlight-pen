Moonlight 호스트 화면 도우미

이 폴더는 Sunshine이 설치된 호스트 PC로 옮겨서 사용합니다.
노트북에는 설치하지 마세요.

설치: 호스트에서 INSTALL-HOST.cmd를 실행합니다.
현재 사용자에게만 설치되고 로그인 때 자동 실행됩니다.
노트북 Moonlight를 새 버전으로 다시 실행한 다음 화면 패널의 ?를 누르세요.
호스트에 연결 확인 알림이 뜨거나 아래 로그에 명령 수신 기록이 있으면 연결된 것입니다.
로그: %LOCALAPPDATA%\MoonlightDisplayHelper\helper.log

복제 / 확장: 각각의 버튼을 한 번 누르면 해당 모드를 요청합니다.
호스트 알림과 로그에 적용 결과가 기록됩니다.
클라이언트 패널에는 성공을 추정해서 표시하지 않습니다.
디스플레이 구성이 변경되는 동안 영상이 잠깐 끊길 수 있습니다.
전환 후 영상이 복구되지 않으면 스트리밍을 다시 연결하세요.

트레이 아이콘의 우클릭 메뉴로 상태 확인, 복제, 확장, 도우미 종료도 가능합니다.
삭제: 이 폴더의 uninstall.ps1을 실행합니다. 화면 모드는 그대로 유지합니다.

호스트 Codex를 이용하려면 '호스트 Codex에 붙여넣기.txt' 내용을 전달하세요.
이것은 설치 파일을 넘겨서 작업을 이어가는 방식이며, Codex 앱 자체의 기기 연결을 자동 설정하지 않습니다.

현재 소스의 호스트 명령 키는 Ctrl+Alt+Shift+D/E/H입니다. 예전 F13/F14/F15 EXE와는 호환되지 않습니다.
